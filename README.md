# Lika's Beauty Hub

Atue como um especialista sênior em UX/UI Design, desenvolvimento Front-end e criação de landing pages de alta conversão para clínicas de estética e salões de beleza.

Crie uma landing page completa, moderna, elegante, feminina, responsiva e focada em gerar agendamentos pelo WhatsApp para a empresa:

LIKA’S CIA DA BELEZA

Instagram:
https://www.instagram.com/likasciadabeleza/

Nome de usuário:
@likasciadabeleza

Endereço:
Rua do Comércio, 4273 – Parque Eldorado

Segmentos principais:
- Unhas
- Cílios
- Tratamentos para pele
- Cabelo
- Depilação
- Maquiagem
- Procedimentos estéticos

O site deverá ser desenvolvido em português do Brasil.

==================================================
1. OBJETIVO PRINCIPAL
==================================================

O principal objetivo da landing page é transformar visitantes em clientes, conduzindo-os para:

1. Agendar um procedimento pelo WhatsApp.
2. Conhecer os serviços oferecidos.
3. Visualizar fotos reais dos trabalhos.
4. Conhecer a estrutura e a experiência profissional da empresa.
5. Acessar o Instagram.
6. Encontrar a localização do estabelecimento.

Não criar login, cadastro de usuário ou área administrativa nesta primeira versão.
